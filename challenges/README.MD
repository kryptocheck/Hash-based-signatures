***
Before we start with challenges, it is good idea to familiarize yourself with this framework. You do not need to use it
and feel free to develop your own implementation in language you prefer, but main goal of this challenge is to solve 
cryptography problem, not programming one. That is the reason that I offer you pre-build framework - you only need to
add code that is specifically needed to solve that challenge, everything else is prepared.
***

You will be always given:
* challenge.md - text of challenge, what are you supposed to solve
* parameters.json - json file with all needed parameters, hashes, keys etc. 
* template.py - prepared template for your solution - for your convenience, part of non-challenge code is written for you
* solution.py - if you are stuck, you can check one of the way how to solve this challenge, with walkthrough.


This is not supposed to be competition, you are solving these challenges only for yourself, so there is no reason to cheat.
